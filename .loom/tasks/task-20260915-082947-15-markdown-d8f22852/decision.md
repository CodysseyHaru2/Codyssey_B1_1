# 결정

- 사용자 요청대로 문서 하나를 Markdown으로 작성하고 항목 1~4의 질문 원문을 모두 포함했다.
- 질문 → 짧은 답변 → 코드 경로와 핵심 발췌로 통일했다. 장문의 이론 설명이나 별도 구현 변경은 하지 않았다.
- 코드 경로는 실제 로컬 파일과 시작 줄을 연결했다. 생략한 코드는 표시하고 발췌가 독립 실행용 코드가 아님을 안내했다.
- 기존 배포·검증 문서를 근거로 기능 설명을 작성하되 Chrome 시험 성공, 실제 폼 전송, 이메일 실재 여부를 주장하지 않았다.
- 개별 변수도 사용할 수 있다는 점과 state 객체가 파일별로 구성되고 수동 렌더 호출이 필요하다는 점을 분명히 했다.
- Loom의 task-execution 및 done-guardrail 계약에 따라 문서와 Task 실행 기록을 로컬 Git 버전에 함께 보존하며 원격 push는 하지 않는다. 별도 활성 Team 정책은 없다.
