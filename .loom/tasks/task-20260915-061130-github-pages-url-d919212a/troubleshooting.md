# 문제 해결과 제한

- sandbox 내 gh auth status가 네트워크 차단으로 invalid token이라고 표시했다. credential을 재발급/삭제하지 않고 승인된 네트워크 환경의 read-only 조회로 기존 keyring 로그인이 유효함을 확인했다. 토큰 본문을 조회하거나 파일/원격 URL에 저장하지 않았다.
- 최초 Pages 조회는 404, 사이트 생성 직후 실제 페이지도 아직 404였다. 기존 게시물이 없는 상태와 정상 반영 대기를 구분했고 build=built 및 실제 HTTP 200으로 확인했다.
- README 패치의 일부 문맥이 일치하지 않아 첫 apply_patch가 원자적으로 실패했다. 현재 문맥으로 다시 적용했고 diff 검사 통과했다.
- 첫 모바일 캡처는 viewport 변경 직후 이전 프레임의 축소 이미지였다. 안정된 상태를 재관찰하고 재캡처했다. 캡처 API의 JPEG 바이트는 sips로 PNG 인코딩만 변환했으며 최종 크기/화면을 검사했다.
- 이전 검증 Task는 배포 시작 뒤 web-user가 DONE 확정했다. 에이전트가 그 결정을 되돌리지 않았고 Chrome 실제 시험은 미완료로 문서에 보존했다.
- 현재 공개 페이지의 핵심 동작에 남은 관찰 실패는 없다. Chrome 최종 기능/반응형/콘솔 확인과 GitHub API의 비인증 제한·폼 데모 한계는 계속 명시한다.
