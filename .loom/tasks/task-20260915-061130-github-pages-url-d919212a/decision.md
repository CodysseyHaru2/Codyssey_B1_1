# 결정

- 채팅의 기존 저장소 선택과 즉시 배포 지시를 실제 foreground 실행 승인으로 기록했다. 공개 Pages는 지정한 GitHub Pages만 사용하고 Sites나 기존 ts.net 서버로 대체하지 않았다.
- 저장소는 이미 PUBLIC이며 ADMIN 권한이 확인됐고 기존 Pages는 없었다. 공개 범위/기본 브랜치를 변경하지 않았다.
- Loom 계약상 로컬 작업과 기록은 develop에서 보존한다. 공개 배포는 별도 독립 브랜치의 allowlist export로 수행해 PDF와 .loom 이력이 외부 저장소에 새로 노출되지 않도록 했다.
- 기존 main과 사용자의 검증 Task 완료 확정을 보존했다. Chrome 미검증이라는 실제 제한도 삭제하거나 성공으로 바꾸지 않았다.
- 공개 API를 실제 제한에 빠뜨리기 위해 반복 호출하지 않았다. 공개 정상 응답과 동일 소스의 제어 응답/자동 테스트를 구분해 증거를 남겼다.
- 공개 README는 전체 로컬 문서 대신 필요한 소개/설계/사용/한계/실제 URL/최종 화면만 생성했다. 캡처는 실제 화면이며 JPEG→PNG 인코딩만 변환했다.
