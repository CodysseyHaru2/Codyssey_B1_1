# 점검과 복구

- sandbox에서 localhost 서버 bind와 curl 연결이 제한돼 같은 명령에 권한을 요청하고 HTTP 200 확인 후 미리보기를 열었다.
- 최초 앱 미리보기는 설정 viewport와 실제 CSS 폭이 달랐다. 해당 탭이 검증 세션에서 사라진 후 같은 브라우저의 새 검증 탭으로 복구했고, 실제 CSS 폭이 요청과 일치하는 6폭 테스트를 다시 수행했다. 임시 viewport는 reset했다.
- Chrome browser 연결은 제공되지 않는다. 앱 브라우저 검증을 Chrome으로 표현하지 않았고 최종 Chrome 확인 필요사항을 남겼다.
- 저장소 코드 결함이나 로컬 정적 화면의 미해결 장애는 없다. 실 API와 문의 로직은 아직 구현하지 않은 후속 범위다.
