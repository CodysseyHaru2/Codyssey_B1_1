# 결정

- 새 프레임워크나 패키지 대신 순수 HTML/CSS/JS의 파일 역할을 유지했다.
- 이름과 직무가 먼저 읽히는 큰 타이포그래피·청록 포인트·중립 배경을 선택하고 과장된 수치/가짜 대시보드를 만들지 않았다.
- 프로필은 HYJ 이니셜, 프로젝트는 소스의 실제 구조를 설명하는 SVG 요약도다. 실사진/실행 화면/실측 차트가 아님을 제목·alt로 명시한다.
- footer를 포함한 6필수 영역과 역할별 시맨틱 요소, label 연결, 키보드 focus, live region을 준비했다.
- CSS 변수로 light/dark 테마를 분리하고 nav Flexbox, Projects auto-fit/minmax Grid, 768/1024 모바일 퍼스트 분기를 사용했다.
- API와 문의 로직은 이 Task에 몰아넣지 않고 후속 Task로 유지했다. 실제 전송 없는 폼 고지를 기본으로 한다.
