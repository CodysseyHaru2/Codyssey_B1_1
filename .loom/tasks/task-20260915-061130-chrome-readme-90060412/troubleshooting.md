# 확인 사항

- Chrome 연결은 네이티브 창으로 복구했고 주소 입력·로드·재로딩까지 확인했지만 실제 콘텐츠는 빈 화면이다. 원인을 임의 단정하거나 보안/사용자 제어를 우회하지 않았다. 안정된 Chrome 시험이 필요하다.
- API 요청 제한 때문에 성공 카드 6폭 검사를 별도 QA 서버 대체 응답으로 수행했다. 실 API 응답 10개와 대체 카드 4개를 혼동하지 않는다.
- QA 서버 bind EPERM 후 같은 localhost 전용 명령에 권한을 요청했다. 검증 후 해당 세션을 Ctrl+C로 종료했다.
- PNG 저장 영역은 설정 viewport 전체보다 작다. 실제 파일 크기를 측정하고 설정값과 구분해 기록했다.
- Loom 폼 Task 확인 필요 사유는 validation evidence 표식 부재다. 코드를 바꾸거나 guardrail을 완화하지 않고 Task별 실제 검증 명령/결과를 보강할 예정이다.
