# 결정

- 학습자용 가상 소개 대신 사용자 원문의 Backend / AI Platform Engineer 정체성과 Loom/DeepQuest/TinyPilot 실제 프로젝트를 중심으로 구성했다.
- 개인 프로젝트와 고용 경력을 구분하고 숙련도 퍼센트·가짜 성과·목표값을 만들지 않는다.
- API 메타데이터는 실제 저장소에만 출처 있는 사례 설명을 결합한다. 실패한 API를 정적 카드로 덮지 않는다.
- 날짜·블로그 불일치는 사용자 확인 전 생략한다. 원본 이력서·전화번호는 기본 공개에서 제외한다.
- 프로필은 사진으로 오인되지 않는 이니셜 이미지, 운영 화면 미재사용 시 실제 구조를 설명하는 요약도로 정의했다.
- Sites 스킬의 정보 위계·가독성·미리보기 기준을 적용하되, React/Shadcn 초기화와 Sites 배포는 사용자의 순수 HTML/CSS/JS·GitHub Pages 요구와 충돌하여 채택하지 않는다.
- 6필수 인터랙션과 테마/API/폼 3상태흐름을 우선한다. 필터·타이핑·실메일·자동 시스템 테마 감지는 기본 범위에 추가하지 않는다.
- 활성화된 Team Policy Snapshot은 없으며 workspace의 develop 브랜치와 Task별 검증·커밋·finish 계약을 따른다.
