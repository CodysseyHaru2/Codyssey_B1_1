# 확인 사항

- sandbox DNS 제한 후 공개 메타데이터만 조회하는 같은 curl 명령에 권한을 요청해 정상 응답을 확인했다.
- 최초 페이지네이션 테스트가 page=1 문자열을 per_page=100에 잘못 매칭했다. URL.searchParams의 정확한 page 비교로 수정하고 6개 전체 재검증을 통과했다.
- 앱 브라우저 실 API 응답은 요청 제한으로 처리됐다. 토큰/비공개 호출이나 정적 성공 대체로 우회하지 않는다.
- Chrome getApp이 장시간 지연/변수 초기화 오류, 캡처 실패 및 앱 변경 보호를 반환했다. 안전 재조회만 수행했고 보호를 우회하지 않았다. 안정된 Chrome에서 실제 성공 화면을 확인해야 한다.
